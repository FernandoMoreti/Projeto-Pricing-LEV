JOINs
    LEFT JOIN serve para ver elementos da tabela da esqueda mesmo que nn tenha na direita

    SELECT aluno.nome, curso.nome
    FROM tb_aluno
    LEFT JOIN tb_aluno_curso.curso ON tb_aluno_curso.aluno_id = tb_aluno.id
    LEFT JOIN tb_curso ON tb_curso.id = tb_aluno_curso.curso_id

    RIGHT JOIN serve para ver elementos da tabela da direita mesmo que nn tenha na esquerda

    SELECT aluno.nome, curso.nome
    FROM tb_aluno
    RIGHT JOIN tb_aluno_curso.curso ON tb_aluno_curso.aluno_id = tb_aluno.id
    RIGHT JOIN tb_curso ON tb_curso.id = tb_aluno_curso.curso_id

    FULL JOIN serve para ver elementos da tabela de todos os lados

    SELECT aluno.nome, curso.nome
    FROM tb_aluno
    FULL JOIN tb_aluno_curso.curso ON tb_aluno_curso.aluno_id = tb_aluno.id
    FULL JOIN tb_curso ON tb_curso.id = tb_aluno_curso.curso_id

Agrupando consultas:
    Group by serve apra usarmos funçoes de agragaçao em consultas

    SELECT nome, sobrenome, COUNT(id)
    FROM tb_aluno
    GROUP BY nome, sobrenome
    ORDER BY nome;

Filtros em consultas agrupadas:
    HAVING

    SELECT tb_curso.nome, COUNT(tb_aluno.id)
    FROM tb_curso
    LEFT JOIN tb_aluno_curso ON tb_aluno_curso.curso_id = curso.id
    LEFT JOIN tb_aluno ON tb_aluno.id = tb_aluno_curso.aluno_id
    GROUP BY nome
    HAVING COUNT(tb_aluno.id) > 0;

Pegar alunos que estao em mais de um curtso e mostrar em quantos cursos eles estão:
    SELECT a.nome, a.sobrenome, COUNT(ac.curso_id) as quantos_cursos
    FROM tb_aluno a
    JOIN tb_aluno_curso ac ON ac.aluno_id = a.id
    GROUPY BY a.nome, a.sobrenome
    ORDER BY quantos_cursos DESC

Curso que tem mais alunos matriculados:
    SELECT c.nome, COUNT(ac.aluno_id) as quantidade_alunos

Como trazer uma consulta em forma de "variavel" ou melhor transforma-la em uma view??
    View seria uma nomeaçao de consultas

    CREATE OR REPLACE VIEW vw_cursos_por_categoria AS
        SELECT categoria.nome AS categoria, COUNT(curso.id) AS numeo_cursos
        FROM categoria
        JOIN curso ON curso.categoria_id = categoria.id
        GROUP BY categoria;

    SELECT *
    FROM vw_cursos_por_categoria;

    CREATE OR REPLACE VIEW vw_cursos_programacao AS
        SELECT nome
        FROM cursos
        WHERE categoria_id = 2;

    SELECT *
    FROM vw_cursos_programacao;
